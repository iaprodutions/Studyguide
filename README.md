# LPC & OPC Study Companion

A phone-friendly installable study app for LPC and OPC preparation.

## Features
- Three sections for every topic: Study, Additional Notes and Review.
- One shared, editable Additional Notes page per topic (not per slide), with an explicit Save button. Notes are stored with the topic and remain available when the app is reopened.
- Edit existing study slides, add slides, and delete slides.
- Edit slide titles and content; add/remove bullet points and paragraphs.
- Insert pictures at the current cursor position in the slide editor. Images are resized and compressed before saving.
- Saving edited slide content automatically creates review cards from its text points. Existing cards are retained.
- Add and delete main topics. Every topic automatically includes the same three sections.
- Topics, topic-wide notes, edited slides, images and review cards are saved in browser local storage. Existing older per-slide notes are consolidated into the topic notes page when possible.
- Basic offline caching for installed app use.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `manifest.webmanifest`, `sw.js` and `README.md` to the repository root.
3. In repository **Settings → Pages**, select deploy from branch and choose `main` / root.
4. Open the published URL in Safari on your iPhone.
5. Use **Share → Add to Home Screen**.

## Important storage note
Your edits are stored in the browser on the device, not in the GitHub repository. Clearing Safari website data or switching devices can remove or hide locally saved changes. Keep a backup of important material. The original Airframes & Flight Controls content is included; the other supplied subjects remain ready for you to populate.
